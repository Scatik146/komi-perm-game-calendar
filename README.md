# «Солнечная восьмёрка» (Шонді кыкьямыс) — коми-пермяцкий игровой календарь

> **Игровая реконструкция.** Не воспроизводит и не заменяет реальные календари,
> существовавшие в крае, округе и местах проживания коми-пермяков; основана на
> коми-пермяцком языке, культуре и особенностях пермских языков.

Календарная система для земель Верхнего Прикамья — Коми-Пермяцкого округа и соседних
районов, где веками жили рядом коми-пермяки, коми, удмурты, русские староверы, волжские
булгары, предки манси и ханты. Календарь солнечно-сезонный: он сводит вместе
староверский суточный круг, время намаза булгарской (ханафитской) традиции и
коми-пермяцкие названия частей дня и ночи.

Восьмеричный счёт на руках и теле: 8 частей суток, 8 дней недели, 6 недель в месяце,
8 месяцев-тотемов, октавы, жизненные круги и эры. Утверждённые решения —
[docs/kalendar.md](docs/kalendar.md), полное описание и проверка — [docs/sistema.md](docs/sistema.md).

Сайт: https://scatik146.github.io/komi-perm-game-calendar/

- **«Солнечные часы»** (*Шонді*) — круг суток для выбранного места, восемь рубежей по Солнцу,
  текущая часть суток по-коми-пермяцки, анбуром и знаками-пасами, Луна и её фаза. Это не
  исторические коми-пермяцкие солнечные часы, а выдумка с коми-пермяцкими словами.
- **«Календарь»** (*Шонді кыкьямыс*) — какой сегодня день по «Солнечной восьмёрке»,
  по григорианскому календарю и по хиджре; перевод дат.
- **«Пишем анбуром»** (*Анбурӧн гижам*) — генератор надписей древнепермским письмом
  с экранной клавиатурой, знаками-пасами и записью дат.
  Азбука одна на четыре языка: коми-пермяцкий, русский и — в мире книги — булгарский
  и угорский (остяки Прикамья). Новые буквы — только точками; кто какими буквами пишет —
  [docs/anbur.md](docs/anbur.md#кто-какими-буквами-пишет).

## Что внутри

| Папка | Что там |
|---|---|
| `docs/` | Описание календарной системы, методика, грамматика, словарь, анбур, история — [оглавление](docs/README.md). |
| `engine/` | Ядро расчётов без зависимостей: Солнце, Луна, рубежи и части суток. |

| `web/` | Сайт-часы (статический, работает офлайн, ставится на телефон). |
| `tests/` | Проверки ядра: порядок рубежей для всех мест на каждый день года, фазы Луны. |

## Как устроены сутки — коротко

Сутки начинаются с заката. Восемь рубежей делят их на восемь частей, части собраны
в четыре четверти, совпадающие со сторонами света:

| Четверть | Рубежи (начало → середина) | Части |
|---|---|---|
| Рыт — вечер, запад | рытмӧм → шонді лэдзчӧм | рытладор, пемдандор |
| Ой — ночь, север | пемдӧм → ойшӧр | ой, асъяой |
| Асыв — утро, восток | югдӧм → шонді петӧм | югдандор, асыв |
| Лун — день, юг | асывшӧр → луншӧр | луншӧрланяс, лун |

Подробно, с обоснованием каждого слова по словарю, — в [docs/sutki.md](docs/sutki.md).

## Запуск

```bash
npm test                    # проверки ядра (Node.js 20+)
./scripts/build-site.sh     # собрать сайт в _site/
cd _site && python3 -m http.server 8000
```

Сайт публикуется на GitHub Pages автоматически при каждом изменении ветки `main`
(файл `.github/workflows/pages.yml`).

## Планы

- Календарный слой: неделя, месяцы, год, праздники.
- Мелкое деление частей суток (сейчас — предварительно по 6 долей, до 48 за сутки).
- Поиск населённого пункта России по названию.
- Приложение для Android и публикация в F-Droid.
