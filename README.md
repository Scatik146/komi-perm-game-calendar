# Коми-пермяцкий игровой календарь

Календарная система для земель Верхнего Прикамья — Коми-Пермяцкого округа и соседних
районов, где веками жили рядом коми-пермяки, коми, удмурты, русские староверы, волжские
булгары, предки манси и ханты. Календарь солнечно-сезонный: он сводит вместе
староверский суточный круг, время намаза булгарской (ханафитской) традиции и
коми-пермяцкие названия частей дня и ночи.

Первая часть — **«Шонді»**, солнечные часы: круг суток для выбранного места, восемь
рубежей по Солнцу, текущая часть суток по-коми-пермяцки, Луна и её фаза.

## Что внутри

| Папка | Что там |
|---|---|
| `docs/` | Описание календарной системы. Начните с [деления суток](docs/sutki.md). |
| `engine/` | Ядро расчётов без зависимостей: Солнце, Луна, рубежи и части суток. |
| `data/` | Места (районы, города Пермского края, городища) и названия на коми-пермяцком языке. |
| `web/` | Сайт-часы (статический, работает офлайн, ставится на телефон). |
| `tests/` | Проверки ядра: порядок рубежей для всех мест на каждый день года, фазы Луны. |

## Как устроены сутки — коротко

Сутки начинаются с заката. Восемь рубежей делят их на восемь частей, части собраны
в четыре четверти, совпадающие со сторонами света:

| Четверть | Рубежи (начало → середина) | Части |
|---|---|---|
| Рыт — вечер, запад | рытмӧм → шонді лэдзчӧм | рытладор, пемдандор |
| Ой — ночь, север | пемдӧм → ойшӧр | ой, асъяой |
| Асыв — утро, восток | югдӧм → шонді петӧм | югдандор, асыв |
| Лун — день, юг | асывшӧр → луншӧр | луншӧрланяс, лун |

Подробно, с обоснованием каждого слова по словарю, — в [docs/sutki.md](docs/sutki.md).

## Запуск

```bash
npm test                    # проверки ядра (Node.js 20+)
./scripts/build-site.sh     # собрать сайт в _site/
cd _site && python3 -m http.server 8000
```

Сайт публикуется на GitHub Pages автоматически при каждом изменении ветки `main`
(файл `.github/workflows/pages.yml`).

## Планы

- Календарный слой: неделя, месяцы, год, праздники.
- Мелкое деление частей суток (сейчас — предварительно по 6 долей, до 48 за сутки).
- Приложение для Android и публикация в F-Droid.
