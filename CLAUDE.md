# Правила работы с «Коми-пермяцким игровым календарём»

Короткие правила для ИИ-помощников (вынесено из навыка `ekonomnaya-sessiya` 25.11.2026: правила проекта — в проекте). Подробности — `docs/README.md`, как ищем слова — `docs/metodika-slov.md`.

- Слова — только проверяемые по словарям: Баталова Р. М., Кривощекова-Гантман А. С. (1985) или Лыткин В. И. (1952). Нет в словаре — нет слова: не придумывать.
- Русский текст — первым и выделен, коми-пермяцкий — рядом.
- Сканы книг не хранить: только выводы, короткие цитаты и ссылки на страницы.
- Перед push — `npm test` и проверка сайта.
- Новое (слова, режимы, правила игры) — сначала согласовать с автором.
- Состояние проекта — ii-komanda `komanda/SOSTOYANIE.md`, раздел календаря.
