# Проект: решения и планы

Технические и организационные решения по сайту и будущему приложению.

## Состав

| Часть | Где | Что |
|---|---|---|
| Ядро расчётов | `engine/` | Солнце (NOAA), Луна (Шлютер), рубежи и части суток, мелкое деление, дата календаря (`kalendar.js`), знаки-пасы (`pasy.js`), транслитерация в анбур и обратное чтение для четырёх языков. Чистый JavaScript без зависимостей |
| Данные | `data/` | места (`places.json`), названия суток (`names.json`), названия календаря (`kalendar.json`), азбука анбура (`anbur.json`), знаки-пасы (`pasy.json`) |
| Сайт | `web/` | «Солнечные часы», «Календарь», «Пишем анбуром». Статический, работает офлайн, ставится на телефон |
| Знаки-пасы | `scripts/build-pasy.py` | собирает `data/pasy.json`, `web/pasy/*.svg` и шрифт `web/fonts/Pasy.ttf` (нужен fontTools); результат хранится в репозитории |
| Проверки | `tests/` | порядок рубежей для всех мест на каждый день года, фазы Луны, транслитерация |
| Документация | `docs/` | календарная система, методика, грамматика, словарь, анбур, история |

## Сайт

- Адрес: https://scatik146.github.io/komi-perm-game-calendar/
- **Название и подача.** Сайт — «Солнечная восьмёрка», игровая реконструкция. Солнечные часы —
  не «коми-пермяцкие солнечные часы»: это выдумка для книги и игры, в которой используются
  коми-пермяцкие слова. Подзаголовок «Игровая реконструкция…» — внизу каждой страницы.
- **Разделы:** «Солнечные часы» (рубежи и части суток пронумерованы парадными знаками-пасами (резами) от заката:
  1 — закат … 8 — аср), «Календарь» (дата по «Солнечной восьмёрке» по-русски, по-коми-пермяцки,
  анбуром, печатными знаками и парадными резами — месяц · неделя · день, затем год; плашка
  с датой резами, картинкой; дата по григорианскому календарю и по хиджре (Умм аль-Кура; названия месяцев — свои,
  без опоры на данные браузера; если браузер не знает этого календаря — табличный расчёт, ±1 день); перевод дат в обе стороны),
  «Пишем анбуром» (генератор надписей; клавиатура знаков-пасов — печатных или парадных;
  режимы «Дата» (и дата резами на плашке — картинкой), «Новый счёт» (восьмеричный, с нулём), «Старый счёт, деньги»).
- **Русская запись даты** — по зверям-защитникам и порядковыми числами: «Месяц Глухаря,
  первая неделя, четвёртый день»; коми-пермяцкие имена (Дозмӧр · Кабыр · нёль) — строкой ниже.
- **Хиджра** — расчётный календарь Умм аль-Кура (Intl в браузере). Как и в «Солнечной
  восьмёрке», мусульманские сутки начинаются на закате, поэтому дата по хиджре берётся для
  тех же суток: вечером она меняется вместе с нашей. Начало месяца по наблюдению молодой
  Луны может отличаться на день.
- Публикуется автоматически при каждом изменении ветки `main` (GitHub Actions →
  Pages). Перед публикацией запускаются тесты.
- Офлайн-режим: service worker, сначала сеть с проверкой свежести (GitHub Pages
  разрешает браузеру держать файлы 10 минут), при отсутствии сети — кэш.
- Местоположение пользователя используется только в браузере и никуда не отправляется.
- **Статистика посещений** — Cloudflare Web Analytics (решение автора 4 ноября 2026): без cookie
  и без личных данных, только число просмотров, страницы, страны и устройства. Смотреть —
  в панели Cloudflare, раздел Web Analytics. GoatCounter из России недоступен.

### Циферблат

- Круг на 24 часа; **начало суток — закат — закреплено сверху**, на месте «12 часов»;
  сутки идут по часовой стрелке — **посолонь** (*шонді ньылат* — «по ходу солнца»).
- Размеры частей меняются день ото дня; круг поворачивается так, чтобы закат был наверху.
- Светлое поле — день от восхода до заката, тёмное — ночь; восемь частей — оттенки.
- Одна стрелка — тень от гномона в центре.
- Засечки по краю — мелкие доли частей (по умолчанию по 6, всего 48; неравные).
- Светлая дуга снаружи — когда Луна над горизонтом; значок фазы — в точке кульминации.

### Интерфейс

- Две кнопки разделов; на каждой надпись в трёх формах: **по-русски (главная, выделена)**,
  по-коми-пермяцки и анбуром. Пользователи лучше знают русский — русский всегда первым.
- Переключатель литературной и иньвенской формы слов.

## Лицензии и авторство

- Код — **Apache 2.0**; тексты в `docs/` и пояснения в `data/` — **CC BY 4.0**.
  Обязательное условие — сохранять файл `NOTICE` и указание автора (Scatik146).
- Шрифты PT Serif, PT Sans (ParaType) и Noto Sans Old Permic — **OFL 1.1**.
  Для анбура используется полный `NotoSansOldPermic-Regular.ttf` из Google Fonts
  (в подмножестве Fontsource нет надстрочных знаков, нужных для й, і, ё).
- **Сканы книг в репозиторий не кладём** — словарь 1985 г. и книга Лыткина под авторским
  правом. В репозитории — только выводы, короткие цитаты и ссылки на страницы.

## Планы

1. **Поиск населённого пункта по названию** (Россия):
   - основной — офлайн-справочник **GeoNames** (CC BY 4.0) с координатами и **часовым
     поясом** каждого пункта; собирается при публикации, поиск с подсказками в браузере;
   - запасной — **Nominatim** (OpenStreetMap, ODbL): только по кнопке «Найти»
     (подсказки при наборе запрещены правилами), не чаще раза в секунду, с подписью
     «© участники OpenStreetMap»; часовой пояс — по ближайшему пункту GeoNames.
2. **Календарная система**: неделя, месяцы, год, праздники — после рассказа автора.
   Затем — показ полной даты и времени в игровом формате.
3. **Календарь** — сделан (4 ноября 2026); дальше — по желанию автора: юлианская дата
   (церковные праздники), праздники и события месяца на экране, поправка ΔT для ранних эр.
4. **Мелкое деление** частей суток по правилам календаря (до 48 долей, неравных).
4. **Android-приложение и F-Droid**: свободная лицензия, сборка из исходников, без Google
   Play Services и трекеров. Вероятный путь — нативное приложение на Kotlin с переносом
   ядра; совпадение расчётов сайта и приложения проверяется общим набором контрольных значений.
5. **Сайт автора** `Scatik146.github.io` — страница со ссылками на все проекты; у каждого
   проекта остаётся свой репозиторий и свой мини-сайт.

## Как запустить

```bash
npm test                    # проверки (Node.js 20+)
node scripts/report.mjs     # сводные таблицы для docs/raschety.md
./scripts/build-site.sh     # собрать сайт в _site/
cd _site && python3 -m http.server 8000
```
